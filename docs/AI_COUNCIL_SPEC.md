# AI 會議室|規格 v1

在 app 裡讓 Claude、ChatGPT、Gemini 照固定規則一起討論,手機隨時可開;每場會議自動產出紀錄與決策,存進決策帳本,之後 AI 與 DD 都查得到。建在既有 AI 中樞(`api/_ai.js`)上,不另接 API。

## 決策

| # | 主題 | 決策 |
| --- | --- | --- |
| 1 | 位置 | app 內新增「AI 會議室」;手機版為主要使用情境 |
| 2 | 兩種模式 | **快問**:單一 AI、依公司文件回答,給所有夥伴與 DD 用;**會議**:三家照流程討論,產出決策 |
| 3 | 記憶 | 記「決策」不記「對話全文」:每場會議寫入決策帳本;新會議自動帶入相關的過去決策 |
| 4 | 共識 | 不用多數決;一律輸出「共識」與「分歧」兩部分,分歧由人裁決 |
| 5 | 殭屍條款 | 已裁決的決策要重開,必須附上新事實,否則系統擋下並顯示原決策 |
| 6 | 權限 | 預設全員可看會議紀錄與決策;個資類資料 AI 一律讀不到(見「資料邊界」) |
| 7 | 不碰程式 | 會議室的 AI 只產出文字;要改程式的結論轉成 CC 任務,照 PR 流程 |

## 會議流程(後端強制,不靠提示詞自律)

1. **開會**:發起人填題目、背景、要決定的事;可附檔案或照片;系統自動帶入相關的過去決策(依標籤與關鍵字比對,上限 5 筆)
2. **獨立作答**(同時送三家,互相看不到):每家回答立場、理由、證據、風險;限 400 字
3. **互相詰問**(最多 2 輪):每家看到另外兩家的答案,只能回覆「同意哪幾點」「反對哪幾點與理由」「對方漏掉什麼」;不得重複自己第一輪的內容
4. **融合**:由一家當整理者(預設輪流,設定頁可改),產出:共識清單、分歧清單(每條附各家立場原文摘要,不可改寫成整理者自己的意見)、建議決定
5. **人裁決**:發起人逐條處理分歧——選一家的、自己寫、或標「待事實」(註明缺什麼資料)
6. **行動建議與紀錄**:產出行動清單(做什麼、誰、期限)、三行重點摘要、完整會議紀錄;決策寫入帳本

任何一步都可以由發起人補充事實,補充內容會帶進下一步。整場最多約 9–12 次 AI 呼叫,開會前顯示預估費用(用 AI 中樞的用量與單價表)。

## 決策帳本

| 欄位 | 說明 |
| --- | --- |
| 編號、日期 | |
| 題目、標籤 | 標籤例:成本、菜單、人事、系統、品牌 |
| 決定 | 一兩句話 |
| 理由 | |
| 各家意見摘要 | 含分歧時誰持什麼立場 |
| 狀態 | 有效 / 已被推翻(連到新決策) / 待事實 |
| 來源會議 | 連到完整紀錄 |
| 裁決人 | |

- 只新增不覆蓋;推翻舊決策時新增一筆並互相連結
- 匯出:每週自動把新決策附加到 repo 的 `docs/DECISIONS.md`(可延後做),讓 CC 開工時也讀得到

## 快問模式

- 單一 AI(預設 Claude,走 AI 中樞路由 `council_ask`),回答時只能根據:決策帳本、公司文件(`docs/` 規格、SOP、GOS 手冊)、app 內可公開的營運數字
- 回答要附來源(哪一筆決策或哪份文件);找不到依據就說「沒有相關資料」,不可自己推測公司規定
- 可一鍵「升級成會議」

## DD 串接

- DD 新增工具:查決策帳本、查會議紀錄摘要(例:「上次碗區怎麼定的?」)
- 第一版 DD 只能查,不能從 LINE 發起會議

## 資料邊界(AI 一律讀不到)

- 入職機密檔、身分證號、銀行帳號、健檢報告(私有桶 `ground-private` 全部排除)
- 個人薪資、分潤明細、個人考評
- 員工私訊內容
- 需要時可在設定頁開「管理者專用會議」,仍不開放上述資料給 AI

## AI 中樞路由(登記在 `AI_ROUTES`)

| 路由 | 用途 | 預設 |
| --- | --- | --- |
| `council_claude` / `council_openai` / `council_gemini` | 會議三席 | 各家文字模型,設定頁可換 |
| `council_synth` | 融合整理者 | 輪流;可固定某家 |
| `council_ask` | 快問 | Claude |

## 頁面

1. **會議列表**:進行中/已結束、標籤篩選、搜尋
2. **會議頁**:時間軸顯示每一步,每家一個顏色;各家回答可展開收合;每一步下方有「補充事實」與「下一步」按鈕;裁決步驟逐條分歧列出選項
3. **決策帳本**:列表、標籤、狀態篩選;每筆可看來源會議
4. **快問**:單一輸入框,答案附來源連結

## 開發批次

1. **批次 A**:會議流程(1–6 步)、會議列表與會議頁、決策帳本、殭屍條款、費用預估
2. **批次 B**:快問模式、資料邊界過濾、DD 查詢工具
3. **批次 C**:自動帶入相關過去決策、`docs/DECISIONS.md` 匯出、權限細分

## 驗收

- [ ] 三家第一輪回答時互相看不到(檢查送出的內容不含其他家答案)
- [ ] 詰問最多 2 輪,系統自動停止
- [ ] 融合結果的分歧清單保留各家原立場,整理者不能把分歧寫成共識
- [ ] 重開已裁決的題目且沒附新事實 → 被擋並顯示原決策
- [ ] 會議結束自動產生紀錄、重點摘要、行動清單,決策進帳本
- [ ] 快問找不到依據時回答「沒有相關資料」
- [ ] AI 送出內容檢查不到個資類欄位
- [ ] DD 問「上次 X 怎麼決定」能回出帳本內容並附連結
- [ ] 手機 390 px 可完整跑完一場會議
- [ ] 每場會議的實際費用記進 AI 用量儀表板
