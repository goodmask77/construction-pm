# GD 入職流程設計稿 v1（2026-10-06，張良「我先出完整設計稿」）

> 目標：GD /prep 自建完整入職流程（主 App 只當參考）。一條流程、內部四步、可分次完成、進度條串起來。
> 前置：新人已「綁定GD 本名」自動建入職名冊卡（v4.56.0 已上線）。本流程＝綁定後，在 /prep「入職資料卡」跟著走。

---

## 一、四步總覽

```
綁定GD 建卡 ─▶ 入職流程卡（/prep）
   Step1 基本資料 ─▶ Step2 繳交表(銀行) ─▶ Step3 簽署(契約+勞資會議) ─▶ Step4 勞健保確認 ─▶ 完成🎉
```
頂部進度條：① 基本資料 ② 繳交表 ③ 簽署 ④ 勞健保　（新人看自己卡在哪、主管看所有入職中的人卡在哪、DD 可追太久的）

---

## 二、各步設計

### Step 1 基本資料（新人填）
| 項目 | 內容 |
|---|---|
| 畫面 | 表單；姓名/部門/員編/到職日自動帶入（名冊已有） |
| 欄位 | 出生年月日・性別・婚姻狀態・身分族群・身分證字號(必填)・外籍工作許可證號+函(選填,台灣籍跳過)・緊急聯絡人 |
| 存 | 名冊卡對應欄位；身分證號屬機密（私有桶/鎖名單守門） |
| 完成 | 進度 +1 |

### Step 2 繳交表（新人填）
| 項目 | 內容 |
|---|---|
| 畫面 | 薪轉銀行說明（文案你提供/沿用中信）＋ 存摺封面照上傳 ＋ 分行名稱/帳號 |
| 欄位 | 存摺封面照(私有桶)・分行名稱・帳號 |
| 存 | 名冊 bankDoc（現有欄位）＋ 分行/帳號新欄位 |
| 完成 | 進度 +1 |

### Step 3 簽署（新人簽，**GD 自建，主 App 只參考**）
| 項目 | 內容 |
|---|---|
| 畫面 | ①勞動契約：顯示內文 → 新人線上簽名 → 存簽署紀錄　②四週變形工時勞資會議同意書：顯示內文 → 簽署 |
| 存 | contractSigned / agreementSigned（時間＋簽名＋IP）＋ 簽署檔進私有桶；**勞資會議同意書另需「公告留存」**（勞檢第一個看） |
| 完成 | 進度 +1 |
| ⚠️ 待提供 | **兩份內文是法律文件，要你/顧問給正式版**，我只做簽署框架 |

### Step 4 勞健保確認（公司做 + DD 雙向）
| 項目 | 內容 |
|---|---|
| 新人 | 這步不用做，等公司加保 |
| DD 提醒公司 | 新人報到當天，DD 提醒張良/行政：「XX 今天報到，記得加勞健保」 |
| 公司確認 | 加完保 → App 勾選「✅ 已加勞健保」（記日期＋操作人） |
| DD 通知新人 | 勾選後 → DD 自動私訊新人：「你的勞健保已加保完成，入職流程全部完成 🎉」 |
| 存 | insConfirmed（日期/操作人） |

## 三、DD 通知點（整條流程）
1. 綁定建卡 → 通知張良（✅ 已上線 v4.56.0）
2. 新人四步全填完送審 → 通知張良核准
3. Step4 報到當天 → DD 提醒張良/行政「記得加勞健保」
4. 加保勾選確認 → DD 通知新人「全部完成」
5. 卡太久（某步停留 N 天）→ DD 追提醒

---

## 四、資料結構（擴充現有名冊卡，不另開一套＝資料一致）
- **現有可用**：idNo(身分證字號)・idDoc(身分證影本)・bankDoc(存摺影本)・laborIns/healthIns(投保額)・contractSigned・onboarding(入職中旗標)・OnboardReviewSection(待審核+進度計算)
- **新增欄位**：birthday・gender・marital・ethnicGroup・foreignPermit・emergencyContact・bankBranch・bankAccount・agreementSigned(勞資會議)・insConfirmed(加保確認)・onboardStep(目前步驟,或由各欄位完成度自動算)
- **機密全走私有桶**：身分證/存摺照/簽署檔（比照現有 private 機制，不進公開圖庫）
- **權限**：新人只能填自己的、看自己進度；完整卡（身分證/薪資）只有主管+本人可開（現有 lockTip 機制）

---

## 五、整合 vs 分開 → 建議「一條流程、內部四步」
- 外殼整合成一條（新人跟著走，不會漏填）；內部各步資料分開存、可分次完成（存摺可後補、契約要簽署流程）
- 只有整合成一條，才能做「進度條」和「DD 追進度」

---

## 六、要你/顧問提供（我不能自己生）
1. **勞動契約正式內文**（法律文件）
2. **四週變形工時勞資會議同意書正式內文**（勞基法 §30-1，餐飲業四週變形必備，勞檢必看）
3. 薪轉銀行說明文案（或沿用現行中信版）

---

## 七、建議實作順序（確認設計後）
1. Step1 基本資料表單 + 進度條框架（先跑通一步）
2. Step2 繳交表
3. Step3 簽署機制（GD 自建；等內文）
4. Step4 勞健保提醒/確認/通知
5. 主管端：入職中列表 + 進度總覽 + 核准
