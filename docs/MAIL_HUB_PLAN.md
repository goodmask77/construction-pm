## 新版原則
1. **信箱清單存 KV**（sp_finance_pm_mailboxes），密碼用 env 金鑰（MAIL_ENC_KEY）加密後才存，設定頁只顯示帳號不回顯密碼。
2. **預設保守**：規則動作只有「封存／貼標／保留白名單」，「移垃圾桶」要在規則上另外勾，且垃圾桶 30 天可救回；永不永久刪除。
3. **先預覽再執行**：每條規則有「會動到哪些信」預覽清單，張良看過才按執行；每日自動執行只跑已確認的規則。
4. **白名單優先**：keep 規則永遠蓋過其他規則（Meta、銀行、政府、法院類預設進白名單）。
5. 敏感資料伺服器端守門：只有審核人看得到信箱頁。

## 開發批次
- **批次1 接入＋整理**：GD 新分頁「信箱」= 信箱清單（新增／停用／測連線）＋每信箱總覽（近 7 天來源排行、未讀數）＋規則（寄件者／主旨關鍵字 → 動作）＋預覽＋執行紀錄＋每日自動跑。
- **批次2 進收件匣**：重要信（規則標「轉收件匣」）進統一收件匣當一個頻道，跟 LINE 官方帳號同一套介面；AI 摘要＋LINE 私訊提醒。
- **批次3 寄信／回信**：從 GD 直接回覆或寄信（用同一組帳號）。
